# Demo de compres per a Daunis · v9

Prototip independent en català. Dades fictícies. Sense correu, ERP, documents ni IA reals. No s’envia res ni es toca cap sistema. Sense dependències de pagament.

## Guió curt

1. **Avui → Reproduir els 5 casos**: rutina dins de tolerància, preu fora de regla, duplicat, error ERP i albarà parcial (80 u. demanades, 60 declarades, 20 pendents). El document no acredita recepció física.
2. **Outlook → Confirmació rutinària → Reproduir**: correu de mostra, vinculació, extracció, regles, resposta simulada i ACK/relectura ERP ficticis.
3. **Outlook → Albarà parcial → Reproduir**: adjunt representat, contrast per línia, esborrany per reclamar el pendent i comprovació de magatzem. Cap stock actualitzat.
4. **Bústia de compres** conserva els 12 exemples de triaje. **Comandes** mostra els registres de la simulació. **Més** conserva límits i abast.

Outlook és només una representació del flux, no el producte de Microsoft. La connexió real requereix validar tipus de bústia, Microsoft 365/Exchange, Microsoft Graph, permisos i consentiment amb IT. Mail.Read, Mail.ReadWrite i Mail.Send són permisos diferents; el model i abast finals no estan decidits. No s’ha concedit cap permís real.

Motor de processos i regles primer; IA com a complement de lectura. Les dades, toleràncies, resultats i indicadors no són dades de Daunis, ni promeses de precisió, estalvi o viabilitat. La demo usa eines gratuïtes; això no implica que el desplegament real sigui gratuït.

Demo pública existent amb noindex/nofollow (no restringeix l’accés). No publicar dades privades. Logotip públic usat només per a aquesta presentació; no és un producte oficial de Daunis.
